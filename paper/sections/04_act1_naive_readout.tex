\section{The Standard Read-Out Understates the Model}
\label{sec:act1}
% ------------------------------------------------------------
% Sumber: findings 01-04. Ini karakterisasi "elektroda standar".
% Fungsi naratif: motivasi (kenapa perlu peta) + baseline angka.
% ------------------------------------------------------------

The read-out used implicitly across the LLM-survey literature---last-token
residual stream, cosine distance, one prompt template---paints a bleak
picture, but a misleading one. Four properties (full details in
Appendix~\ref{app:anisotropy}):

\paragraph{Weak and type-uneven fidelity.}
Fidelity computed over all same-type cell pairs pooled together is
$\rrho\approx0.17$ (peak at layer 17; we use ``pooled'' in exactly this
sense throughout), but this pools sharply unequal types: AGE$\times$POLPARTY and
EDUCATION$\times$INCOME reach $\rrho\approx0.50$ while
RACE$\times$RELIG is $\rrho=0.07$ (n.s.). % finding 01-02
Cross-type pairs correlate \emph{negatively}---inter-group distances are
only meaningful within an attribute type.

\paragraph{Severe anisotropy, and the obvious fix fails.}
Group embeddings share a dominant common direction
($\lVert\bar{x}\rVert / \overline{\lVert x\rVert} = 0.95$): all cells
clump. Mean-centering doubles the \emph{pooled} correlation
($0.185\!\to\!0.301$) yet \emph{decreases} every within-type correlation
(e.g., AGE$\times$POLPARTY $0.455\!\to\!0.375$)---the pooled gain is a
between-type scale artifact. % finding 03 + koreksi
This is consistent with depth-wise ``diversity collapse''
\citep{divcollapse2026}.

\paragraph{Noisy neighborhoods.}
Top-5 neighbor precision against ground truth is ${\sim}2\times$ chance in
all six types but only $0.35$--$0.48$ absolute: about 2 of 5 nearest
neighbors are right. % finding 04
Applications that borrow statistical strength from neighbors inherit this
noise; a consistency-regularization pilot built on this read-out failed
accordingly (Appendix~\ref{app:lgroup}).

\paragraph{The open question this creates.}
Weakness of \emph{one} read-out does not establish weakness of the
\emph{model}: the information may be present but stored elsewhere. The
residual stream sums the outputs of all attention heads and FFN blocks,
so any signal carried by a few components can be diluted by the rest.
The next section reads every component separately.
